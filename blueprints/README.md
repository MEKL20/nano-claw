# Blueprints

This directory contains reusable system/workflow blueprints.

Each blueprint should live under:

```text
blueprints/<category>/<blueprint-name>/
```

Recommended files per blueprint:

```text
README.md      # short explanation, scope, usage
BLUEPRINT.md   # full reusable spec/concept
```

## Categories

- `memory/` — memory architecture, recall, promotion, and review workflows.

Future categories may include:

- `ops/` — operational/server workflows
- `agents/` — assistant orchestration patterns
- `prompts/` — reusable prompt/system patterns
- `security/` — safety/security checklists and workflows
